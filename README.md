# Fonten web

Web estática pública de Fonten.

Páginas principales:

- `index.html`: presentación de la app.
- `privacidad.html`: política de privacidad.
- `Terminos.html`: términos y condiciones.
- `contacto.html`: soporte y contacto.
- `Eliminar-cuenta.html`: instrucciones públicas para eliminar una cuenta.

Dominio configurado en `CNAME`: `www.fontenapp.com`.
