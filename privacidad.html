Política de privacidad

Última actualización: 11 de mayo de 2026

Esta política explica cómo Fonten trata la información necesaria para crear cuentas, gestionar organizaciones, miembros, publicaciones, denuncias y pagos dentro de la app.

Para consultas de privacidad, soporte o moderación, escribe a fontenapp.support@gmail.com.

1. Responsable y contacto

El responsable del tratamiento es el titular de Fonten. Puedes contactar para cualquier cuestión relacionada con privacidad, soporte, moderación o ejercicio de derechos en fontenapp.support@gmail.com.

2. Datos que tratamos

Según el uso de la app, Fonten puede tratar estas categorías de datos:

  • Datos de cuenta: correo electrónico, nombre, apellidos, nombre de usuario, identificador de usuario, rol y credenciales gestionadas por el proveedor de autenticación.
  • Datos de organizaciones: organizaciones creadas o asociadas, nombre, imagen, código de unión, miembros, solicitudes de acceso y roles.
  • Contenido interno: publicaciones del tablón, reacciones, estados de lectura o interacción y fechas asociadas.
  • Moderación y seguridad: denuncias, bloqueos, registros necesarios para revisar abusos, fraude o usos no autorizados.
  • Pagos: configuración de tarifa mensual, estado de pagos, método de pago, fechas de pago y datos necesarios para operar con Stripe u otros proveedores compatibles.
  • Soporte: mensajes enviados al equipo de Fonten e información necesaria para resolver la consulta.
  • Datos técnicos: información de sesión, dispositivo, sistema operativo, dirección IP, registros de errores y actividad necesaria para seguridad y funcionamiento.

3. Permisos del dispositivo

Fonten puede solicitar acceso a la galería de fotos cuando un organizador elige una imagen para una organización. Este permiso se usa únicamente para la acción solicitada y la app no accede a tus fotos sin permiso.

4. Pagos y proveedores externos

Los pagos se procesan mediante Stripe u otros proveedores externos compatibles. Fonten no almacena números completos de tarjeta ni credenciales bancarias completas. El proveedor de pago puede tratar datos necesarios para procesar pagos, verificar cuentas, prevenir fraude y cumplir obligaciones legales.

5. Finalidades

Usamos los datos para:

  • Crear, autenticar y mantener cuentas de usuario.
  • Permitir crear organizaciones, unirse a ellas y gestionar miembros o solicitudes.
  • Mostrar publicaciones internas, reacciones y contenido de cada organización.
  • Gestionar pagos mensuales, estados de pago y configuración de Stripe.
  • Prestar soporte y responder solicitudes.
  • Revisar denuncias, aplicar bloqueos y prevenir abusos o fraude.
  • Mantener la seguridad, corregir errores y mejorar el funcionamiento de la app.
  • Cumplir obligaciones legales, fiscales o regulatorias cuando correspondan.

6. Base legal

Tratamos datos para prestar el servicio solicitado, cumplir obligaciones legales, proteger la seguridad de usuarios y organizaciones, y atender intereses legítimos como prevención de fraude, moderación y mejora del funcionamiento. Cuando sea necesario, el tratamiento se basará en tu consentimiento.

7. Compartición de datos

Compartimos datos solo cuando es necesario para prestar el servicio: con proveedores técnicos como Supabase para autenticación, base de datos, almacenamiento y funciones backend; con proveedores de pago como Stripe; con tiendas de aplicaciones cuando corresponda; y con autoridades si existe obligación legal.

8. Conservación y eliminación

Conservamos los datos mientras tu cuenta esté activa o mientras sean necesarios para prestar el servicio, resolver incidencias, prevenir abusos o cumplir obligaciones legales. Puedes eliminar tu cuenta desde Ajustes o siguiendo las instrucciones de la página Eliminar cuenta. Al eliminarla, se borrarán o desvincularán los datos asociados salvo aquellos que deban conservarse por motivos legales, fiscales, antifraude o de seguridad.

9. Derechos del usuario

Puedes solicitar acceso, rectificación, eliminación, oposición, limitación o portabilidad de tus datos cuando la normativa aplicable lo permita. También puedes retirar consentimientos concedidos desde el sistema operativo o solicitando soporte en fontenapp.support@gmail.com.

10. Seguridad

Aplicamos medidas técnicas y organizativas razonables, incluyendo autenticación, reglas de acceso, políticas de seguridad en base de datos y comunicaciones cifradas cuando el proveedor lo permite. Ningún sistema es infalible, pero trabajamos para proteger la información frente a accesos no autorizados, pérdida, alteración o divulgación indebida.

11. Menores

Fonten no está dirigida a menores que no tengan edad suficiente para usar servicios digitales según la normativa aplicable. Si detectamos una cuenta creada sin autorización válida, podremos eliminarla.

12. Cambios de esta política

Podemos actualizar esta política para reflejar cambios legales, técnicos o funcionales. La versión vigente estará publicada en esta página con su fecha de actualización.
